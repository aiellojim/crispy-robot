把使用者剛描述的新坑寫進 `docs/lessons.md`，步驟：

1. 讀 `docs/lessons.md`，確認「踩坑紀錄」目前最大編號 N 與既有條目——若同一個坑已存在，改為更新該條目而非新增。
2. 以固定格式追加為第 N+1 條（缺的欄位先問使用者，不要留空或編造）：

```
### #N+1 <一句話標題>
- 日期：<今天，YYYY-MM-DD>
- 觸發情境：<什麼操作/什麼條件下會踩到>
- 規則：<以後該怎麼做，具體可執行>
- 正例：<正確做法，最好含程式碼片段或指令>
- 反例：<錯誤做法，說明會發生什麼>
```

3. 若條目總數超過 60，提醒使用者：「lessons 已超過 60 條，建議開一次專門 session 合併去重」。
4. 回報寫入的完整條目內容與編號。
